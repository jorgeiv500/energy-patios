# Data Redistribution Notice

This repository separates code licensing from data redistribution.

The source code is released under the MIT License. Public raw data remain under the terms of their original providers and are not relicensed by this repository. Large raw files, third-party PDFs, and restricted provider files should not be redistributed here unless the authors confirm that the source license permits it.

Lightweight derived files in `data/processed/` and reference result tables in `results/tables/` can be archived with the DOI release when their redistribution is permitted. The release notes should identify any files excluded from the archive and point readers to `docs/data_inventory.md` for original source locations.
